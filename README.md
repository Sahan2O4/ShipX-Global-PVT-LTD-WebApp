# SHIPX Global (PVT) LIMITED WebApp

[Visit the live site](https://shipx.lk)

---

## Project Overview

This is a **React-based web application** developed for **SHIPX Global (PVT) LIMITED**, a shipping logistics company based in Colombo, Sri Lanka. The website showcases their services, cargo operations, and company updates to clients and partners.

The project features:

- Fully responsive React design
- Company branding with logos and custom favicon
- Sections for client reviews, service overview, and company updates
- Integration of multimedia content (videos and images)
- Optimized for modern web performance

---

## Technologies Used

- **React** – Frontend framework
- **HTML5 / CSS3** – Structure and styling
- **JavaScript (ES6+)** – Interactivity
- **Git & GitHub** – Version control
- **cPanel Hosting** – Production deployment

---



1. Run `npm run build` to generate the production build.
2. Upload the contents of the `build` folder to your web host (`public_html` on cPanel).
3. Ensure the `.htaccess` file exists for React routing support.
